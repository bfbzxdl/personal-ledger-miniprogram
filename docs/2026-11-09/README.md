## 8. 夜间排障：打开热点提示「网络不给力」

**现象**：本地 `pages/news/home` 打开即报 `网络不给力，点我重试`。

**定位**（在开发者工具 appservice 里直接调 `wx.cloud.callFunction`）：

| 阶段 | 返回 | 含义 |
| --- | --- | --- |
| 部署前 | `-501000 FUNCTION_NOT_FOUND` | 云函数 `news` 根本没上传（云端只有 `admin`、`daily-content`） |
| 部署后 | `-504002 functions execute fail / 145 code exit unexpected` | 运行时是 **Nodejs16.13**，`cheerio`/全局 `fetch` 需要 Node 18+，函数加载即崩溃 |
| 惰性加载后 | `ping` 正常、`listNews` 返回 `{ok:true,total:0}` | 查询链路可用；页面从「网络错误」变成空态「今日数据还没准备好」 |
| 初始化时 | `-504003 Invoking task timed out after 3 seconds` | 函数超时只有 **3s**，建集合+导种子/抓取 19 源都跑不完 |

**根因**：① `news` 未部署；② 部署后默认运行时 Node 16、超时 3s；③ 客户端把三类失败都映射成「网络不给力」，掩盖了真实原因。

**已修**：
- 客户端错误分类（`-501000` 未部署 / `-504002`、`-504003` 执行失败或超时 / 其他才算断网），文案可直接指导排查；
- 查询类 action 惰性加载 `pipeline`，Node 16 下 `ping`/查询不再崩溃；
- 新增 `action=bootstrap`：一次建 7 个集合 + 导入 19 源种子（未配 `ADMIN_TOKEN` 时仅空库首次可调用）。

**仍需在控制台手动改**（CLI 部署不带这两项）：云开发控制台 → 云函数 → `news` → 配置 → 运行时 `Nodejs18.15`、超时 `60s`、内存 `256MB`。改完后执行：

```bash
node scripts/devtools-bootstrap.cjs   # 建集合 + 导种子
# 再触发一次抓取（需 ADMIN_TOKEN，或在控制台用测试模板调用 action=fetch）
```

| 项目 | 内容 |

## 1. 产品概述
### 1.1 背景与目标
个人台账小程序旨在帮助个人管理“时间”与“金钱”两大核心资产。
- **时间台账**：记录每日工时，通过日历和汇总了解时间投入。
- **金钱台账**：记录日常收支，培养储蓄习惯。
- **情绪价值**：通过首页每日壁纸与鼓励语，为用户提供日常激励。

## 3. 功能需求
### 3.1 首页：每日壁纸与鼓励语 【新增】
- **展示形式**：采用大卡片式布局（圆角+阴影），卡片背景为每日壁纸，中央悬浮鼓励语。
- **切换规则**：
  - 壁纸：按星期（周一至周日）每天自动切换7张本地内置壁纸。
  - 鼓励语：按日期（1-30号）循环展示内置文案库（核心文案：“每天节省一点点，退休别墅靠大海”）。
- **扩展性**：当前为本地数据，代码层预留网络API接口，未来可无缝升级为云端/网络获取。

### 3.2 工时记录模块 (UI重构)
- **UI规范**：全面采用**大卡片式布局**。表单区、汇总区、日历区分别独立为带有圆角和柔和阴影的卡片，提升视觉层级和呼吸感。
- *(原有表单、日历、详情、汇总业务逻辑同 v1.0，此处略)*

### 3.3 记账本模块（基础版 MVP） 【新增】
#### 3.3.1 月度统计卡片
- 展示当前月份的：总收入、总支出、总结余。
- 切换月份时数据联动。

#### 3.3.2 记一笔表单
- **金额**：数字键盘输入，保留两位小数。
- **类型**：支出 / 收入 切换。
- **分类**：
  - 支出预设：餐饮、交通、购物、娱乐、住房、医疗、教育、其他。
  - 收入预设：工资、奖金、兼职、理财、其他。
- **备注**：选填，最多20字。
- **保存**：校验金额 > 0 后保存，刷新列表和统计。

#### 3.3.3 流水列表
- 按日期倒序分组展示（如：今天、昨天、7月31日）。
- 每条显示：分类图标（emoji）、分类名称、备注、金额（收入绿色，支出红色）。
- **操作**：长按支持删除（需二次确认）。

### 3.4 补充细化决策
- **壁纸资源**：本地 7 张渐变占位图（monday.jpg ~ sunday.jpg），后续可替换同名文件。
- **鼓励语**：内置 30 句文案库，按日期循环。
- **记账本月份切换**：顶部左右箭头，联动统计卡片。
- **分类图标**：使用 emoji。

## 4. 数据模型设计
### 4.1 记账记录 (LedgerRecord) 【新增】
```json
{
  "id": "1722502800000_xyz789",
  "date": "2026-08-01",
  "type": "expense",          // income / expense
  "amount": 35.50,            // 金额
  "category": "餐饮",         // 分类
  "note": "和同事吃火锅",      // 备注
  "createdAt": 1722502800000
}
```
*存储方案*：`wx.setStorageSync('ledger_records_YYYYMM', records)`，按月分块。

## 5. 页面结构
- `pages/home/home`：首页（壁纸卡片+鼓励语）
- `pages/work/index/index`：工时记录（大卡片UI）
- `pages/work/detail/detail`：工时详情
- `pages/ledger/index/index`：记账本（统计+记账+流水）

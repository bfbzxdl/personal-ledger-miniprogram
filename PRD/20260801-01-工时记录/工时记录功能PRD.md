## 1. 产品概述

### 1.1 背景
个人台账小程序新增"工时记录"功能，用于记录每日工作时长，通过日历视图和月度/年度汇总，帮助用户了解自己的时间投入情况。

### 1.2 目标
- 快速记录每日工时（含午休扣除）
- 日历视图直观展示每天工时
- 支持月度、年度工时汇总

### 1.3 非目标（本期不做）
- 不做多人协作 / 团队打卡
- 不做工时审批流程
- 不做导出报表

---

## 2. 用户画像
- **目标用户**：个人开发者/上班族（付先生本人）
- **使用场景**：每天下班或空闲时记录当天工作时间，月底查看汇总

## 3. 功能需求

### 3.1 记录表单（页面顶部）

**3.1.1 当前时间展示**
- 页面顶部展示当前日期时间，格式：`2026-08-01 星期六 17:30`
- 数据来源：`new Date()` 实时获取

**3.1.2 日期选择框**
- 默认值：**当前日期**
- 可点击弹出日期选择器（picker mode="date"）
- 允许选择任意日期（可补录历史记录）

**3.1.3 时间段选择框（开始/结束）**
- 两个时间选择器：**开始时间**、**结束时间**
- 默认值：开始 **08:00**，结束 **13:00**
- 粒度：**30分钟**（可选 00:00~23:30）
- 结束时间必须晚于开始时间（否则提示"结束时间需晚于开始时间"）
- 自动计算并反显**工作总时长**：`结束时间 - 开始时间`
  - 示例：08:00-13:00 → 显示"工作总时长：5小时"

**3.1.4 午休时间选择框**
- 标题：**午休**
- 用于扣除午休时长
- 粒度：30分钟
- 默认值：**1小时**（12:00-13:00 常规午休）
- 可选范围：0 ~ 4小时（步长0.5）

**3.1.5 实际工时自动计算**
- 实际工时 = 工作总时长 − 午休时长
- 实时联动显示：选完时间段和午休后自动更新
  - 示例：08:00-13:00（5h）− 午休1h = **实际工时4小时**
- 若结果为 0 或负数，提示"实际工时不能为0"

**3.1.6 确定按钮**
- 点击后校验通过 → 保存记录 → 表单刷新为默认值 → 日历同步更新
- 保存成功提示（toast："记录成功"）

### 3.2 日历视图（页面底部）

**3.2.1 日历展示**
- 月视图日历（周日起始）
- 顶部显示当前查看的**年/月**，支持**左右切换月份**
- 每个日期格子：
  - 第一行：日期数字
  - 第二行：当天**总工时**（如 `4h` / `7.5h`）
  - 无记录的日子：第二行留空或显示 `-`

**3.2.2 点击日期**
- 点击有记录的日期 → 进入**当日详情页**
- 点击无记录的日期 → 可提示"当天暂无记录"或同样进入详情页（空列表）

### 3.3 当日详情页

**3.3.1 记录列表**
- 展示当天所有工时记录，每条包含：
  - 时间段（08:00-13:00）
  - 午休时长（1h）
  - 实际工时（4h）
  - 记录时间

**3.3.2 长按操作**
- 长按某条记录 → 弹出操作菜单：
  - **修改**：回到表单页，预填该条记录数据，保存后覆盖更新
  - **删除**：二次确认（弹窗"确定删除该记录？"）→ 删除

**3.3.3 当天合计**
- 详情页顶部展示当天总工时

### 3.4 汇总统计

**3.4.1 月度汇总**
- 默认展示**当月总工时**
- 切换月份（日历顶部箭头）→ 汇总联动显示该月总工时

**3.4.2 年度汇总**
- 支持切换年份，展示**该年总工时**
- 页面顶部增加年份切换（或长按月份名切换年份）
- 月度视图切换月份时，若跨年自动更新年份

## 4. 数据模型设计

### 4.1 工时记录（本地存储）

```json
{
  "id": "1722502800000_abc123",   // 唯一ID（时间戳+随机后缀）
  "date": "2026-08-01",            // 日期 YYYY-MM-DD
  "startTime": "08:00",            // 开始时间 HH:mm
  "endTime": "13:00",              // 结束时间 HH:mm
  "lunchBreak": 1,                 // 午休时长（小时，0.5步长）
  "workHours": 4,                  // 实际工时（小时）
  "createdAt": 1722502800000       // 创建时间戳
}
```

### 4.2 存储方案（本地存储）

| Key | 内容 |
|:----|:------|
| `work_records_202608` | 2026年8月的所有记录数组（按月分块） |
| `work_summary_cache` | （可选）汇总缓存 |

- 存储方式：`wx.setStorageSync('work_records_YYYYMM', records)`
- 优点：按月读取，切换月份快速加载

## 6. 交互与校验规则

| 场景 | 规则 |
|:----|:------|
| 结束时间 ≤ 开始时间 | 提示"结束时间需晚于开始时间"，不允许保存 |
| 实际工时 ≤ 0 | 提示"实际工时不能为0"，不允许保存 |
| 午休 > 工作总时长 | 提示"午休时长不能超过工作时间"，不允许保存 |
| 保存成功 | toast "记录成功" |
| 删除记录 | 二次确认弹窗 |
| 修改记录 | 表单预填原数据，保存后覆盖（同ID更新） |

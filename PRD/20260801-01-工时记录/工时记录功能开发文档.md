## 5. 数据模型（定稿）

### 5.1 WorkRecord

```typescript
interface WorkRecord {
  id: string          // `${timestamp}_${random4}`
  date: string        // YYYY-MM-DD（= 今天，记录时固定）
  startTime: string   // HH:mm（半小时粒度）
  endTime: string     // HH:mm
  lunchStart: string  // 午休开始 HH:mm（如 12:00）
  lunchEnd: string    // 午休结束 HH:mm（如 13:00）
  workTotal: number   // 工作总时长 = endTime - startTime
  lunchHours: number  // 午休时长 = lunchEnd - lunchStart
  workHours: number   // 实际工时 = workTotal - lunchHours（保留1位小数）
  createdAt: number   // 时间戳
}
```

### 5.2 存储

| Key | 内容 |
|:----|:------|
| `work_records_YYYYMM` | 当月记录数组（按月分块） |

**去重规则：** 同一天 `startTime + endTime + lunchStart + lunchEnd` 完全相同 → 提示"该时段已记录"不保存

### 5.3 汇总

```typescript
// 月度（当月块累加）
sumMonth(records) => reduce(workHours)

// 年度（1-12月块累加），仅在查看12月时展示
sumYear(year) => sum(all 12 blocks)
```

// 半小时粒度时间数组: ['00:00','00:30',...,'23:30']
function timeSlots() {
  const slots = []
  for (let h = 0; h < 24; h++) {
    slots.push(`${pad(h)}:00`, `${pad(h)}:30`)
  }
  return slots
}

// 字符串时间转分钟

// 计算时长(小时, 保留1位)
function calcHours(start, end) { return Math.round((toMinutes(end) - toMinutes(start)) / 6) / 10 }

// 校验
function isValidRange(start, end) { return toMinutes(end) > toMinutes(start) }

// 日历网格
function buildMonthGrid(year, month, records) {
  // 返回 42 格（6行7列），含前后月补位

// 格式化
function formatHours(h) { return h % 1 === 0 ? `${h}h` : `${h.toFixed(1)}h` }

### 6.3 utils/storage.js

```javascript
function monthKey(date) { return `work_records_${date.slice(0, 7).replace('-', '')}` }

function getMonthRecords(monthStr) { return wx.getStorageSync(monthKey(monthStr)) || [] }

function saveRecord(record) {
  const key = monthKey(record.date)
  const list = getMonthRecords(record.date.slice(0, 7))
  list.push(record)
  wx.setStorageSync(key, list)
}

function updateRecord(record) {
  const key = monthKey(record.date)
  const list = getMonthRecords(record.date.slice(0, 7))
  const idx = list.findIndex(r => r.id === record.id)
  if (idx > -1) list[idx] = record
  wx.setStorageSync(key, list)
}

function deleteRecord(id, date) {
  const key = monthKey(date)
  const list = getMonthRecords(date.slice(0, 7))
  wx.setStorageSync(key, list.filter(r => r.id !== id))
}

function getAllRecordsOfYear(year) {
  let all = []
  for (let m = 1; m <= 12; m++) {
    all = all.concat(getMonthRecords(`${year}${pad(m)}`))
  }
  return all
}

module.exports = { getMonthRecords, saveRecord, updateRecord, deleteRecord, getAllRecordsOfYear }
```

**核心方法：**

| 方法 | 逻辑 |
|:----|:------|
| onLoad | 初始化：nowText、today、默认值、读当月数据、刷新汇总 |
| onStartChange / onEndChange | picker change → 重算 workTotal / actualHours |
| onLunchStartChange / onLunchEndChange | 同上重算 lunchHours / actualHours |
| recalc() | 统一计算：workTotal=calcHours(start,end); lunchHours=calcHours(ls,le); actual=workTotal-lunchHours |
| onSubmit | ①校验区间 ②校验实际>0 ③查重(同天同时间段) ④isEdit? updateRecord : saveRecord ⑤toast ⑥重置表单(编辑态退出) ⑦刷新日历汇总 |
| onDayTap(e) | 跳转 `pages/work/detail/detail?date=...` |
| onPrevMonth / onNextMonth | viewMonth±1，跨年更新viewYear → 读数据+刷新汇总 |
| onYearLongPress | wx.showActionSheet 年份选择（近5年）→ 更新 viewYear、刷新年度汇总 |
| onShow | 检测 globalData.editRecord → 预填表单进入编辑态 |

**编辑态：**
- 进入编辑：按钮文字"保存修改"、isEdit=true、editId=记录id
- 日期、id 保持原值；只改 时间段/午休
- 保存：updateRecord（同id覆盖）

**pickerrange：** 使用 `timeSlots` 数组，`picker mode="selector"`，选中下标。

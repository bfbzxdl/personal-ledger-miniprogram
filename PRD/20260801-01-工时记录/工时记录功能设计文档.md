## 3. 数据结构设计

### 3.1 工时记录 Record

```typescript
interface WorkRecord {
  id: string          // 唯一ID: `${timestamp}_${random}`
  date: string        // 日期 YYYY-MM-DD
  startTime: string   // 开始时间 HH:mm（半小时粒度）
  endTime: string     // 结束时间 HH:mm
  lunchBreak: number  // 午休时长（小时，0.5 步长）
  workHours: number   // 实际工时（小时，保留1位小数）
  createdAt: number   // 创建时间戳
}
```

### 3.2 存储结构（本地存储，按月分块）

| Storage Key | Value | 说明 |
|:------------|:------|:------|
| `work_records_202608` | `WorkRecord[]` | 2026年8月全部记录 |
| `work_selected_month` | `"2026-08"` | 当前查看的月份（页面状态） |

**读取规则：**
- 月份切换 → 读取对应 `work_records_YYYYMM`
- 写入/更新/删除 → 按记录 `date` 定位到对应月份块

### 3.3 汇总计算

```typescript
// 月度汇总（直接累加）
sumMonth(records: WorkRecord[]): number {
  return records.reduce((sum, r) => sum + r.workHours, 0)
}

// 年度汇总（读取1~12月所有块）
sumYear(year: number): number
```

## 4. 核心模块设计

### 4.1 utils/time.js（dayjs 封装）

```typescript
// 暴露方法
formatNow(): string                // 当前时间格式化: "2026-08-01 星期六 17:30"
calcWorkHours(start, end): number  // 计算工作总时长(小时): 结束-开始
calcActualHours(start, end, lunch): number  // 实际工时 = 总时长 - 午休
isValidRange(start, end): boolean  // 校验结束时间 > 开始时间
buildMonthGrid(year, month, records): Cell[]  // 生成日历格子数据
formatHours(h): string             // 4.5 → "4.5h" / 5 → "5h"
```

**日历格子 Cell 结构：**

```typescript
interface Cell {
  day: number        // 日（1-31），空白格为 null
  dateStr: string    // "2026-08-01"
  isCurrentMonth: boolean  // 是否当月
  isToday: boolean   // 是否今天
  totalHours: number // 当天总工时（无记录=0）
  hasRecord: boolean
}
```

### 4.2 utils/storage.js（存储封装）

```typescript
// 暴露方法
getMonthRecords(month: 'YYYY-MM'): WorkRecord[]
saveRecord(record: WorkRecord): void      // 新增（推入对应月份块）
updateRecord(record: WorkRecord): void    // 修改（同ID替换）
deleteRecord(id: string, month: string): void  // 删除
getAllRecordsOfYear(year: number): WorkRecord[]  // 年度汇总用
```

### 4.3 components/work-calendar（日历组件）

**组件属性（properties）：**

| 属性 | 类型 | 默认值 | 说明 |
|:----|:----|:------|:-----|
| year | Number | 当前年 | 显示的年份 |
| month | Number | 当前月 | 显示的月份（1-12） |
| records | Array | [] | 当月记录（用于算每日工时） |

**组件事件（triggerEvent）：**

| 事件 | 参数 | 说明 |
|:----|:-----|:------|
| `daytap` | `{ dateStr, hasRecord }` | 点击某天 |
| `prevmonth` | — | 切上个月 |
| `nextmonth` | — | 切下个月 |
| `yearlongpress` | — | 长按月份名（切换年份） |

**渲染逻辑：**
- 用 dayjs 计算当月第一天星期几 → 生成 6x7 网格（含前后月补位）
- 每个格子：日期数字 + 当日总工时（`formatHours`）
- 今天高亮、有记录的日子加标记色

### 4.4 主页面 pages/work/index

**data 结构：**

```typescript
data: {
  nowText: string,        // 顶部当前时间
  date: '2026-08-01',     // 选择日期（默认今天）
  startTime: '08:00',     // 开始时间（默认08:00）
  endTime: '13:00',       // 结束时间（默认13:00）
  lunchBreak: 1,          // 午休（默认1小时）
  workTotal: 5,           // 工作总时长（联动）
  actualHours: 4,         // 实际工时（联动）
  viewYear: 2026,         // 日历显示年份
  viewMonth: 8,           // 日历显示月份
  monthRecords: [],       // 当前月份记录
  monthTotal: 0,          // 月度总工时
  yearTotal: 0,           // 年度总工时
}
```

**关键方法：**

| 方法 | 说明 |
|:----|:------|
| `onLoad` | 初始化：当前时间、默认值、加载当月数据、刷新汇总 |
| `onDateChange` | 日期选择器 change |
| `onStartChange / onEndChange` | 时间选择器 change，联动计算 workTotal/actualHours |
| `onLunchChange` | 午休选择器 change，联动计算 |
| `onSubmit` | 校验 → 保存 → toast → 刷新日历和汇总 |
| `onDayTap` | 跳转详情页 `work/detail?date=YYYY-MM-DD` |
| `onPrevMonth / onNextMonth` | 切换月份，重新读取数据+汇总 |
| `onYearLongPress` | 长按月份名 → 年份选择弹窗 |

**校验规则（提交时）：**

```
1. endTime > startTime          否则: "结束时间需晚于开始时间"
2. workTotal - lunchBreak > 0   否则: "实际工时不能为0"
3. lunchBreak <= workTotal      否则: "午休时长不能超过工作时间"
```

### 4.5 详情页 pages/work/detail

**接收参数：** `date`（YYYY-MM-DD）

**data 结构：**

```typescript
data: {
  date: '2026-08-01',
  dayRecords: [],    // 当天记录列表
  dayTotal: 0,       // 当天总工时
}
```

**长按操作：**
- `bindlongpress` 触发 → `wx.showActionSheet`（修改/删除）
- **修改**：跳回主页面并携带记录数据（`getApp().globalData.editRecord` 或通过页面栈传参）→ 表单预填 → 保存时同 ID 覆盖
- **删除**：`wx.showModal` 二次确认 → `storage.deleteRecord()` → 刷新列表

## 5. 页面流程

### 5.1 记录流程（主页面）

```
[进入页面]
   ↓
[显示当前时间] [日期默认今天] [时间段默认08:00-13:00] [午休默认1h]
   ↓
[用户调整时间段/午休] → 自动计算 workTotal / actualHours 联动显示
   ↓
[点击确定]
   ↓ 校验失败 → toast 提示
[校验通过 → storage.saveRecord() → toast"记录成功"]
   ↓
[表单重置默认值] [日历格子更新] [月度/年度汇总刷新]
```

### 5.2 查看流程

```
[主页面日历] ──点击某天──→ [详情页]
                              ├── 当天记录列表 + 合计
                              ├── 长按 → 修改（回主页面预填）
                              └── 长按 → 删除（二次确认）

[主页面日历顶部] ──左右切换──→ 月份变化 → 汇总联动
[主页面日历顶部] ──长按月份──→ 年份切换 → 年度汇总联动
```

## 7. 关键风险与对策

| 风险 | 对策 |
|:----|:------|
| TDesign Calendar 格子自定义能力不足 | work-calendar 组件内部按 dayjs 自研网格渲染（纯UI渲染，不引第三方），对外接口一致 |
| Vant 与 TDesign 样式冲突 | 各自独立作用域；若有冲突，日历类统一用 TDesign，交互类统一用 Vant |
| 本地存储容量（10MB上限） | 记录单条约300字节，月记录<100条，年<1MB，远低于上限 |
| 长按"修改"跨页传参复杂 | 通过 `getApp().globalData.editRecord` 传递，主页面 onShow 检测并预填 |
